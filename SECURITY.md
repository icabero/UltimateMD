# Seguridad

## Versiones con soporte

Solo la última versión publicada recibe arreglos de seguridad.

## Avisar de una vulnerabilidad

No abras una issue pública. Usa el [aviso privado de vulnerabilidades](https://github.com/icabero/UltimateMD/security/advisories/new) e incluye los pasos para reproducirla, la versión y tu sistema.

Es un proyecto personal, así que la respuesta puede tardar unos días.

## Qué protege UltimateMD

- La app y el servidor MCP solo llegan a archivos dentro de cada vault.
- Las notas y los archivos HTML se muestran aislados de la app.
- Las notas no salen de tu equipo.

Más detalle en la [sección de privacidad y seguridad del README](README.md#privacidad-y-seguridad).

Los instaladores aún no están firmados, así que descárgalos solo desde las [versiones oficiales](https://github.com/icabero/UltimateMD/releases).
